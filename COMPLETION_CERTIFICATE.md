## 🚀 Getting Started in 3 Steps

### Step 1: Install & Build (15 minutes)
```bash
# Frontend
cd INVENTORY
npm install
npm run build -- --production

# Backend
cd Backend/EmployeeAssetManagement.Api
dotnet build
dotnet ef database update
```

### Step 2: Configure (10 minutes)
- Update connection strings in `appsettings.json`
- Set API URLs in web part settings
- Configure SharePoint site collection

### Step 3: Deploy (varies)
- Follow [DEPLOYMENT.md](DEPLOYMENT.md)
- Choose Azure or on-premises
- Run verification tests

**Total setup time: 1-2 hours**
